## Commit subjects and PR titles

Use `[scope] subject`, choosing a scope from the table by the change's main purpose and omitting `[scope]` if none fits.

| Scope | Use for |
| --- | --- |
| `dev` | Development tooling, dependencies, and repository configuration or documentation. |
| `blog` | Blog content. |
| `link` | External link entries. |
| `site` | Site functionality and presentation. |
